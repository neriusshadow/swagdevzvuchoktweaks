# 🎵 SWAGdev ZVUCHOKtweaker

> Официальное расширение от **neriusshadow / SWAGdev** для музыкального раздела **«Звучок»** в социальной сети **huEVO** ([huevo.su](https://huevo.su/zvuchok) и [huevo.departament.site](https://huevo.departament.site/zvuchok)).
> Аутентичный интерфейс в стиле **ВКонтакте 2016 года**, Discord Rich Presence статус, управление плеером и полезные твики!

---

## ✨ Возможности

- 🎧 **Discord Rich Presence (RPC)**:
  - Отображает текущий трек, исполнителя и статус (Играет / На паузе) прямо в профиле Discord.
  - Идеально точная шкала времени воспроизведения (01:23 / 03:45) без рывков.
  - Кнопка **«Слушать в Звучке»** со ссылкой на трек.
  - Заглушка обложки `zvuchok_logo.png` в аутентичном ретро-стиле huEVO.
  - Защищенный зашифрованный Discord Client ID.
  - Поддержка кастомного Client ID в настройках.
- 🎚 **10-полосный эквалайзер + Bass Boost + Reverb**:
  - Полноценная обработка звука через Web Audio API прямо в браузере.
  - Пресеты: «Клубный бас», «Рок», «Вокал», «Концертный зал», «ВК 2007 Lo-Fi».
  - Ручная регулировка полос от -12 дБ до +12 дБ, ползунки Bass Boost и Реверберации.
- ⚡ **Pitch & Speed Control (Nightcore / Slowed + Reverb)**:
  - Регулировка скорости трека (0.5x – 2.0x) и переключатель фиксации тональности прямо в плеере.
- 📦 **Пакетное скачивание плейлиста (.zip) и экспорт (.m3u)**:
  - Скачивание всех треков текущего плейлиста в один ZIP-архив с красивыми именами файлов.
  - Экспорт в `.m3u` для импорта в AIMP, Winamp, VLC и мобильные плееры.
- 🌙 **Таймер сна (Sleep Timer)**:
  - Автоматическое выключение музыки через 15, 30 или 60 минут с плавным затуханием громкости.
- 📊 **Личная статистика прослушиваний**:
  - Вкладка со статистикой: Топ-5 исполнителей, самый прослушиваемый трек, суммарное время прослушивания.
- 🎛 **Управление плеером из попапа**:
  - Переключение треков (⏮ / ⏭), пауза/воспроизведение (▶ / ⏸), интерактивная перемотка (Seek bar).
- 📥 **Быстрое скачивание MP3**:
  - Кнопка скачивания рядом с каждой аудиозаписью на сайте.
- 💬 **VK-стиль уведомления**:
  - Всплывающее компактное окно при переключении песен в духе старого ВКонтакте.
- ⌨ **Горячие клавиши**:
  - Пробел / Медиа-клавиши для воспроизведения, Alt + Стрелки для переключения песен.

## 🚀 Установка

### 🦊 Mozilla Firefox
1. Откройте `about:debugging#/runtime/this-firefox` в адресной строке.
2. Нажмите **«Загрузить временное дополнение...»** (Load Temporary Add-on).
3. Выберите файл `manifest.json` в папке проекта или собранный `swagdev-zvuchoktweaker-firefox.zip` / `swagdev-zvuchoktweaker-firefox.xpi`.

### 🌐 Google Chrome / Chromium / Яндекс.Браузер / Edge / Brave
1. Откройте `chrome://extensions` (или `browser://extensions`).
2. Включите переключатель **«Режим разработчика»** (Developer mode) в правом верхнем углу.
3. Нажмите **«Загрузить распакованное расширение»** (Load unpacked) и выберите папку проекта (или папку `build/chromium`).

## 🎮 Настройка Discord RPC

Браузерные расширения изолированы от прямого доступа к сокетам операционной системы. Расширение поддерживает **два полностью автоматических способа связи**:

### Способ 1: Встроенный SWAGdev RPC Bridge (0 зависимостей)
В проект включен готовый легкий bridge-сервер на чистом Python 3:
- **macOS:** Дважды кликните по файлу `bridge/start_bridge_mac.command` в Finder.
- **Windows:** Дважды кликните по файлу `bridge/start_bridge_windows.bat`.
- **Linux:** Запустите `bridge/start_bridge_linux.sh`.

*Сервер мгновенно соединится с запущенным Discord Desktop и передаст треки без необходимости ставить сторонние библиотеки.*

### Способ 2: Через arRPC / Vesktop / Legcord
Если вы пользуетесь сторонними клиентами Discord (Vesktop, Legcord) или у вас уже запущен `arRPC` на порту `1337`, расширение подключится к нему **автоматически без запуска моста**.

## 🛠 Сборка проекта

Для компиляции свежих релизных архивов запустите:
```bash
python3 build.py
```
Скрипт создаст:
- `swagdev-zvuchoktweaker-chromium.zip` — пакет для магазинов Chrome/Edge.
- `swagdev-zvuchoktweaker-firefox.xpi` / `.zip` — пакет для Firefox AMO.
